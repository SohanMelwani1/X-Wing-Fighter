# October 19: journal-1 R2-D2

I started with making R2-D2 cylinder shape and sphere for the main body. Next I added the bottom part of cylinder using loft. However, I still have to add the part supporting it, im pretty sure i'm going to use loft for it since it's organic shape, anyways, towards the end making it it started looking like a weird R2-D2 but that's cus i haven't finished it at least it's recognizable.
