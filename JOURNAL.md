# October 19: journal-1 R2-D2

I started with making R2-D2 cylinder shape and sphere for the main body. Next I added the bottom part of cylinder using loft. Later I did the arms, while making them i learnt and used a new feature called 'overall slot' which helped me making an oval kind of shape faster than using lines and arc, however it took sometime to get it the way I wanted it to be. then I added the other part of the arm. However, I still have to add the part supporting it, im pretty sure i'm going to use loft for it since it's organic shape, anyways, towards the end making it it started looking like a weird R2-D2 but that's cus i haven't finished it at least it's recognizable.
